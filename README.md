# Jogo do Número

Um jogo simples de adivinhação de números, desenvolvido como exercício de lógica de programação.

## Sobre o projeto

O objetivo do jogo é descobrir qual número foi sorteado pelo sistema. A cada tentativa, o usuário recebe uma dica informando se o número secreto é maior ou menor que o valor informado.

## Como jogar

1. Abra o projeto no navegador.
2. Digite um número dentro do intervalo definido pelo jogo.
3. Veja a resposta:
   - "Seu número é maior!"
   - "Seu número é menor!"
   - "Parabéns! Você acertou!"
4. Continue tentando até acertar o número.

## Objetivo

Adivinhar o número secreto com o menor número de tentativas possível.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Se preferir, também pode iniciar um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

## Estrutura do projeto

- `index.html` — estrutura da interface
- `style.css` — estilos da página
- `script.js` — lógica do jogo

## Observação

Este projeto foi criado como parte de estudos em lógica de programação e pode ser adaptado e melhorado conforme o aprendizado avança.
